How a request is routed

  1. Policy first. A local rules engine scores the prompt: length, privacy cues, and whether it looks like heavy analysis.

  3. Hybrid fallback. Firebase AI Logic still falls back if the preferred path is unavailable, and the response badge shows which path actually ran.
